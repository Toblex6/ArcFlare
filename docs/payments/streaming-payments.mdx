Stream funds per-criterion as the reviewer confirms each requirement. The job's total budget is split deterministically across criteria (tranche per requirement) and released individually upon confirmation.

---

## Creating a Nanopayment Stream

```typescript
const stream = await fetch('/api/jobs/nanopay/open', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', cookie: merchantCookie },
  body: JSON.stringify({
    jobId: '181386',
    criteria: {
      jobId: '181386',
      description: 'Complete backend implementation',
      requirements: [
        'Complete backend API implementation',
        'Write unit tests for all endpoints',
        'Deploy to staging and verify',
      ],
      deadlineUnix: Math.floor(Date.now() / 1000) + 86400,
    },
  }),
});
const { streamId, trancheCount, totalBudget, trancheAmounts } = await stream.json();
console.log('Stream ID:', streamId);
```

## Releasing a Tranche

```typescript
const rel = await fetch('/api/jobs/nanopay/release', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', cookie: merchantCookie },
  body: JSON.stringify({ jobId: '181386', requirementIndex: 0 }),
});
console.log('Tranche 0 tx:', rel.txHash);
```

## Closing the Stream

```typescript
const close = await fetch('/api/jobs/nanopay/close', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', cookie: merchantCookie },
  body: JSON.stringify({ jobId: '181386' }),
});
console.log('Closed:', close.closedAt);
```

## Checking Status

```typescript
const status = await fetch('/api/jobs/nanopay/status', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', cookie: merchantCookie },
  body: JSON.stringify({ jobId: '181386' }),
});
console.log('On-chain released indexes:', status.status.onChain.releasedIndexes);
```

## Authorization

- **Open**: Job client (poster) — caller must control `job.clientSCA`
- **Release**: Job client OR evaluator (authorized reviewer) — on-chain signer is always the poster's wallet
- **Close**: Same as release
- **Status**: Any authenticated caller with access to the job

---

## Tranche Accounting

For a budget of 30,000 base units (0.03 USDC) and 3 criteria:

| Criterion | Amount |
|-----------|--------|
| 0 | 10,000 |
| 1 | 10,000 |
| 2 | 10,000 (remainder added to last) |

**Deterministic bigint math**: floor division, remainder added to the final tranche. Total released never exceeds budget.

## Known Limitations

Arc Testnet USDC applies a per-transfer fee to the recipient (~0.0014–0.0022 USDC for contract→EOA transfers, measured on payroll/swap contracts). This contract's bookkeeping tracks exact amounts; the worker's actual wallet gain is `amount - fee`. Verify deltas on mainnet.
